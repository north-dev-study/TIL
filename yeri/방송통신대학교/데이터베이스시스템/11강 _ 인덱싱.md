## 인덱스란

- DB는 SQL문이 입력시 디스크에 있는 데이터를 블록 형태로 메모리에 올려 찾는다.
-> 레코드가 억단위로 많다면? I/O 시간이 과도하게 발생. 데이터를 찾는데 오랜 시간이 걸린다
-> 인덱스가 필요!

- 인덱스는 탐색키를 이용해 해당 레코드 블럭을 빠르게 찾는다.
탐색키 : 파일에서 레코드를 찾는데 사용되는 컬럼 / 컬럼의 집합


- 인덱스를 통한 탐색과정
> 1. 탐색키로 구성된 인덱스 블록을 메모리에 올린다.
> 2. 레코드를 찾아 해당 레코드의 포인터에 연결된 블록을 메모리에 올려 컬럼을 찾는다.
