## 트랜잭션이 생긴 이유

### 데이터 동시 접근의 문제
- 하나의 데이터에 여러 사용자가 동시에 접근하게되었을때 데이터 일관성이 훼손될 수 있다.
- 데이터의 일관성, 무결성을 지키기 위해 작업처리순서를 일부 조정해야한다.


## 트랜잭션 개념

- 데이터베이스를 조작하기 위한 하나의 논리적 단위를 이루는 일련의 데이터베이스 연산의 집합

ex) 예금 인출 : read - 연산 - write
