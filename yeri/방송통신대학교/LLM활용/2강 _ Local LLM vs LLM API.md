
### Local LLM 
- 해당 AI의 하드웨어를 통해서 LLM을 사용할수있는것
- 내 로컬에도 오픈소스를 다운받아 LLM백엔드로 구동 가능 > 작은 sLIM으로 쓰거나, API로 접근
- 장점 : 데이터 보안에 이점 / 비용 효율성 / 인터넷 독립성
- 단점 : 하드웨어 설치 어려움 / 기술적 난이도

- 모델 선택의 기준 : 용도(코드를 잘 짜는지, 텍스트를 잘 짜는지 ...)


추론 엔진 (Inference Engine)
: 모델 파일을 실제로 로드하고 실행하는 엔진
: 하드웨어와 모델 사이의 다리 역할
: 최적화 기법 적
