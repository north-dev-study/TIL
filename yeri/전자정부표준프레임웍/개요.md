> Spring MVC를 중심으로 공공기관 프로젝트에서 공통으로 사용할 구조·라이브러리·개발 규칙·공통 기능을 묶어 놓은 프레임워크


```
Java
 └─ Spring Framework / Spring MVC
      └─ 전자정부표준프레임워크
           ├─ 정해진 프로젝트 구조
           ├─ 추가 라이브러리
           ├─ 공통 컴포넌트
           ├─ 개발 표준과 규칙
           └─ Eclipse 기반 개발 도구
```


### Flow
```
브라우저
  ↓
Tomcat 등의 WAS
  ↓
Spring MVC
  ↓
전자정부프레임워크 라이브러리
  ↓
업무 코드
  ↓
DB
```


### 특징
- Maven 기반 프로젝트
- Tomcat 같은 외부 WAS에 WAR로 배포
- Spring MVC 사용
- Controller, Service, DAO 계층 분리
- XML 기반 Spring 설정이 많음
- MyBatis 또는 구버전 프로젝트에서는 iBATIS 사용
- JSP를 화면으로 사용하는 경우가 많음
- 전자정부프레임워크 전용 공통 클래스와 유틸리티 사용


### 공통 컴포넌트 가져오는 방법
```
프로젝트 선택
  ↓
New 또는 eGovFrame 메뉴
  ↓
Common Component 선택
  ↓
필요한 기능 선택
  ↓
관련 컴포넌트와 의존 컴포넌트 확인
  ↓
소스 코드와 설정을 프로젝트에 생성
  ↓
DB 스크립트 실행
  ↓
프로젝트 환경에 맞게 수정
```
