## 이중화 (duplexing)

> 하나의 시스템에서 두개의 동일한 요소를 사용해 병렬로 운영하는 것

- ex) 네트워크 통신에서 데이터를 전송하는 경우, 이중화를 사용하여 동일한 데이터를 두 개의 경로로 전송하면 한 경로가 실패하더라도 다른 경로에서 데이터를 전송할 수 있음


## 이원화 (dual homing)

> 두 개의 독립적인 시스템을 사용하여 서비스를 보호하는 방법

- ex) 서버에 대한 이원화를 구성하면, 두 개의 서버가 있고 하나는 작동 중이고, 다른 하나는 백업 모드에 있음. 작동 중인 서버에 장애가 발생하면 백업 서버가 자동으로 작동하도록 구성할 수 있음
