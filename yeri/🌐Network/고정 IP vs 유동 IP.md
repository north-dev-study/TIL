## 고정 IP(Static) 

> 수동으로 장치에 설정한 IP 주소. 재부팅되거나 네트워크 재연결시에도 동일함

- 서버 설정에 유리 : 일정한 위치를 유지해야하는 장치 설정에 유리
- 접근 권한 제어 관리 용이
- 네트워크 통신 안정적
- 유료임


## 유동 IP(DHCP)

DHCP : Dynamic Host Configuration Protocol
> 네트워크 내 장치에서 자동으로 임시 IP 주소를 할당받음. 네트워크 재접속시 또는 일정 시간이 지난 후 재할당 되거나 재사용될 수 있음

- 대규모 네트워크에 적합
- 관리가 쉬움
