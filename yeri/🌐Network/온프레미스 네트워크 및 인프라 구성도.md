인터넷 : 수 많은 컴퓨터가 연결된 전 세계적인 네트워크
웹(www) : 인터넷 위에서 정보를 보여주는 **어플리케이션**


## 네트워크 통신 방법

**TCP/IP**
각 서버와 클라이언트는 IP (Internet Protocol)가 할당되어있다.
요청응답시 데이터를 한번에 보내는게 아니라, 데이터를 작게 나눠보내는데
순서대로 정상적으로 전송이 되었는지를 확인하는 프로토콜


**HTTP**
HTML을 주고받는 프로토콜
client와 server가 통신할 때, client가 브라우저, server가 web인 경우에는 HTTP를 통해 통신함


## 네트워크 핵심 장비

**라우터**
WAN(Wide Area Network) 과 LAN(Local Area Network) 구간을 연결하는 장비

**스위치**
LAN 라우터 내부의 여러 컴퓨터를 연결하는 장비


**방화벽**
보안설정. 접속 가능한 IP/port 설정


## 기타 개념

**CDN (Content Delivery Network)**
전 세계 곳곳에 데이터를 복사해 사용자와 가까운 서버에서 전송되도록 하는 네트워크

**DMZ(Demilitarized Zone)**
외부에서 접속이 가능한 서버.
외부 인터넷과 내부 네트워크 사이에 위치한 중간 지대로, 보안 위협으로부터 내부 자산 보호
ex) 웹서버, 메일서버
