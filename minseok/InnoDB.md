- 메모리와 디스크로 나뉜다
- 메모리(RAM) : 매우 빠름. 나노초(ns)단위로 접근.
- 디스크(SSD/HDD) : 메모리보다 수백~수만 배 느리다. 마이크로초(us)~밀리초(ms) 단위로 접근.

### 메모리 영역
- 자주 사용하는 데이터를 메모리에 캐싱
#### 버퍼 풀 (Buffer Pool)
- InnoDB에서 가장 중요한 메모리 영역
- 성능을 위해 데이터를 메모리에 임시 보관하는 캐시.
- 테이블 데이터와 인덱스 데이터를 페이지(Page) 단위로 캐싱
- 페이지는 InnoDB가 데이터를 읽고 쓰는 최소 단위(기본 16KB)
- 쿼리가 요청한 데이터가 버퍼 풀에 있으면 (Buffer Pool Hit) > 메모리에서 바로 읽는다 > 빠름
- 없으면 (Buffer Pool Miss) > 디스크에서 읽어와서 버퍼 풀에 올린 다음에 읽는다 > 느림
- 버퍼 풀의 히트율이 높을수록 디스크 I/O가 줄어들고 성능이 좋아진다.
- 데이터베이스 전용 서버라면 물리 메모리의 최대 80% 까지 버퍼 풀로 할당하는 것을 권장.

### 디스크 구조
- 전체 데이터는 디스크에 안전하게 저장
