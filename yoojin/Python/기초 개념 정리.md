# 파이썬(Python) 기초 개념 정리

## 1. 파이썬이란?
- 문법이 간결하고 읽기 쉬운 고급 프로그래밍 언어
- 인터프리터 언어로, 코드를 한 줄씩 실행
- 동적 타이핑(Dynamic Typing) 언어: 변수 선언 시 타입을 명시하지 않음

---

## 2. 변수와 자료형

### 2.1 변수 선언
```python
x = 10          # 정수(int)
y = 3.14        # 실수(float)
name = "Alice"  # 문자열(str)
is_active = True  # 불리언(bool)
```

### 2.2 기본 자료형
| 자료형 | 설명 | 예시 |
|--------|------|------|
| `int` | 정수 | `10`, `-5` |
| `float` | 실수 | `3.14`, `-0.5` |
| `str` | 문자열 | `"hello"` |
| `bool` | 참/거짓 | `True`, `False` |
| `NoneType` | 값 없음 | `None` |

### 2.3 형 변환
```python
int("10")     # 문자열 -> 정수
str(10)       # 정수 -> 문자열
float("3.5")  # 문자열 -> 실수
```

## 3. 자료구조

### 3.1 리스트 (List) — 순서 있음, 변경 가능
```python
fruits = ["apple", "banana", "cherry"]
fruits.append("orange")
fruits[0]        # "apple"
fruits[-1]       # 마지막 원소
```

### 3.2 튜플 (Tuple) — 순서 있음, 변경 불가
```python
point = (3, 4)
```

### 3.3 딕셔너리 (Dictionary) — key-value 구조
```python
person = {"name": "Alice", "age": 25}
person["name"]        # "Alice"
person["job"] = "dev" # 새 항목 추가
```

### 3.4 집합 (Set) — 중복 없음, 순서 없음
```python
numbers = {1, 2, 3, 3, 2}  # {1, 2, 3}
```

## 6. 반복문

### 6.1 for문
```python
for fruit in ["apple", "banana", "cherry"]:
    print(fruit)

for i in range(5):   # 0, 1, 2, 3, 4
    print(i)
```

### 6.2 while문
```python
count = 0
while count < 5:
    print(count)
    count += 1
```

### 6.3 반복 제어
```python
break      # 반복 종료
continue   # 다음 반복으로 건너뜀
```

## 7. 함수
```python
def greet(name, greeting="안녕"):
    return f"{greeting}, {name}!"

print(greet("철수"))          # 안녕, 철수!
print(greet("영희", "hi"))    # hi, 영희!
```

- `def`로 정의
- `return`으로 값 반환
- 매개변수에 기본값 설정 가능
- `*args`, `**kwargs`로 가변 인자 처리 가능

## 8. 클래스와 객체지향

```python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        return f"{self.name}가 소리를 냅니다."

class Dog(Animal):          # 상속
    def speak(self):
        return f"{self.name}가 짖습니다."

dog = Dog("멍멍이")
print(dog.speak())
```

- `__init__`: 생성자
- `self`: 인스턴스 자기 자신을 가리킴
- 상속(Inheritance), 다형성(Polymorphism) 지원
